Nesta pasta eu demonstro vários "proofs-of-concept" de minhas habilidades para programar com simples exercícios-programa, executados no contexto de minha graduação. Muitos destes exercícios foram realizados no contexto da disciplina de Introdução a Ciência da Computação para Ciências Exatas, no Instituto de Física e no Instituto Oceanográfico da USP.

Considero estes exercícios fáceis, e de simples resolução. Foram feitos sem uso de IA, apenas digitando em frente ao console.

O mais robusto deles será o projeto 2, que realiza uma calculadora financeira com seus respectivos calculos de juros.
